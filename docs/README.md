## Evidence and maintenance boundaries

Active Markdown, README guidance, HTML companions, figures, and the authored
thesis describe the current state. Notebook outputs, saved model responses,
experiment source snapshots, and imported expert text retain their original
provenance; they are not rewritten to make old runs resemble today's pipeline.
Notebooks remain exploratory or historical unless the current notes explicitly
identify their results as current evidence.

Record meaningful improvements in the nearest existing note, including what
changed, why, the supporting evidence, and what remains untested. Do not turn
software checks or model judgments into claims about students or learning.
